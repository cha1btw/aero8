# AERO8 — frontend MVP

Інтерактивний демо-сайт мережі АЗС. Показує ціни, схематичну карту станцій, фільтри за пальним і сервісами, калькулятор заправки та кабінет AERO8 Club. Усі дані локальні й демонстраційні; ERP, білінгу та справжньої реєстрації немає.

## Запуск

Потрібен Node.js 20.19+ або 22.12+.

```bash
npm ci
npm run dev
```

Відкрийте адресу, яку виведе Vite. Для перевірки:

```bash
npm test
npm run build
npm run preview
```

Ціни та станції знаходяться в `src/lib/demo.ts`. Зображення головного екрана згенероване для цього макета та зберігається в `public/images/`. Надане посилання Google Maps винесене окремо від демонстраційної карти.
